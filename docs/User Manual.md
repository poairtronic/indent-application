# User Manual

## 1. Getting Started
To log in, navigate to the application URL, input your email and password, and click Log In.

## 2. Navigating the Dashboard
The dashboard displays overall metrics (Pending Indents, Material stock alerts, Costs, etc.).

## 3. Creating an Indent
1. Select **Indent Module** on the sidebar.
2. Click **Create New Indent**.
3. Fill out material specs, quantities, and target date.
4. Click **Submit for Approval**.
