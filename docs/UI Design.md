# UI Design Guidelines

## Color Palette (Enterprise Dark Theme Tokens)
- **Primary Background**: `#0F172A` (Slate Dark)
- **Surface Card**: `#1E293B` (Elevated Container)
- **Primary Accent**: `#3B82F6` (Electric Blue)
- **Success Status**: `#22C55E` (Emerald Green for Completed / Financial Closure badges)
- **Warning Status**: `#F59E0B` (Amber for In-Progress / Cost Variance Warning badges)
- **Danger Status**: `#EF4444` (Red for Delivery Exception / Critical Alert badges)

## Layout & Architecture
- **Sidebar Navigation:** Collapsible navigation panel highlighting department work queues and executive dashboards.
- **Executive Notification Header:** Header with unread notification badge popover, breadcrumbs, search, and user profile menu.
- **Two-Loop Work Center Views:** Department-specific task cards for Design, Stores Fulfillment, Production Execution, and Accounts Cost Verification.
- **Executive Dashboard:** Real-time monitoring feed and cost variance visualization for Senior Managers & General Managers.
