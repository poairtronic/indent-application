# UI Design Guidelines

## Color Palette
- **Primary**: Deep Blue / Slate
- **Secondary**: Emerald Green (for approved status / positive actions)
- **Warning**: Amber / Orange
- **Danger**: Red / Crimson
- **Neutral**: Grays and Soft Off-Whites for panels and backgrounds

## Layout Design
- Sidebar Navigation for main modules.
- Header showing User details, Role, Notifications, and Settings toggle.
- Clean tables with pagination and action columns.
